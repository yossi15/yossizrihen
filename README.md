# תאילנד 2026 — מתכנן מסלול

אפליקציית ווב לתכנון טיול בתאילנד ב-24.9–11.10.2026: מפה אינטראקטיבית של
אטרקציות ושל בתי חב"ד ומסעדות כשרות, מסלול יומי, לוח שבתות וחגים עם זמנים
מחושבים, ומידע מעשי לתרמילאים.

## מסכים

| מסך | מה יש בו |
| --- | --- |
| **מפה** | 190 מקומות ב-5 אזורים, בתצוגת מפה או רשימה מקובצת לפי עיר, (פוקט, קוסמוי, קופנגן, בנגקוק, קו פי פי), סינון לפי אזור וקטגוריה, כרטיס פרטים עם טיפ וקישור ניווט, ושמירת מועדפים |
| **מסלול** | 18 ימים כציר זמן לפי הבסיסים שנסגרו, כל יום עם מעברים, הערות ורשימת מקומות |
| **כשרות ושבת** | סוכות, שמיני עצרת ושמחת תורה ושבת בראשית — זמני נרות, שקיעה וצאת הכוכבים, ורשימת בתי חב"ד ומסעדות כשרות |
| **מידע** | כשרות בסבן אילבן, לאכול כשר, טלפוני חירום, בנגקוק (גגות, קניונים, חייטים), כסף, סים, תחבורה, הונאות, בריאות, מזג אוויר, טיפים ואריזה |

## איך זה בנוי

- **Next.js 16** (App Router) + **React 19** + **Tailwind 4**.
- **Leaflet** עם אריחי CARTO Voyager, נטען דינמית בצד הלקוח בלבד (`ssr: false`).
- כל התוכן סטטי ב-`src/lib/trip/` — אין API, אין מפתחות, והדף כולו נבנה מראש.
- זמני שבת מחושבים באלגוריתם השקיעה של NOAA לפי הקואורדינטות של כל אזור
  (`src/lib/trip/shabbat.ts`), לא נשלפים משירות חיצוני.
- מועדפים ומקומות שהמשתמש מוסיף נשמרים ב-`localStorage` של הדפדפן בלבד.

## הוספת מקומות אישיים

כפתור **"+ מקום שלי"** במפה פותח טופס: שם, עיר, קטגוריה, שיוך אופציונלי ליום
במסלול, הערה, ומיקום. את המיקום אפשר להזין בשלוש דרכים — הדבקת קישור מגוגל
מפות, הקלדת `lat, lng`, או בחירת נקודה בלחיצה על המפה. המקומות מופיעים על
המפה עם סימון נפרד, ניתנים לסינון בצ'יפ "שלי", ומופיעים בתוך היום שאליו
שויכו במסך המסלול.

## הערות על התוכן

מחירים, שעות ומיקומים בתאילנד משתנים תכופות. מקומות שמסומנים
**"מיקום משוער"** דורשים אימות בגוגל מפות, ובתי חב"ד ומסעדות כשרות דורשים
אימות טלפוני לפני נסיעה — במיוחד בחגים. זמני השבת מחושבים ומיועדים לתכנון;
לאימות סופי מול לוח מקומי.

ההזמנה לחתונה שהייתה בשורש הפרויקט עברה ל-`/wedding`.
